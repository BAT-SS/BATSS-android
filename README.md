## 📱 About B.A.T. Admin

**B.A.T. Admin** is the private operational mobile management app for **B.A.T. Software Solutions**, featuring:
- **Biometric & Device PIN Lock** with 5-minute configurable grace period.
- **Client & Project Manager**: Real-time project tracking, offers, and milestones.
- **Payment & Accounts Console**: Revenue totals, pending dues, and INR formatting.
- **Native Android Sharing**: Direct WhatsApp and Email sharing for invoices.
- **Automated In-App Updates**: Seamless over-the-air updates queried directly from this repository.
